## College Event Management System
# Description
The College Event Management System is a web-based application designed to simplify the process of event management at colleges. It allows students, faculty, and staff to register for events online by providing essential details such as name and contact information. The system securely stores all data in a backend database, ensuring easy access for event organizers and administrators.

#Features
Online Event Registration: Students, faculty, and staff can register for events through a simple online form.
Data Storage: All user information is stored securely in a backend database using MySQL.
User Management: Admins can view and manage registrations easily.
Responsive Design: The system is designed to be responsive and user-friendly on different devices.


# Technologies Used
Frontend: HTML, CSS
Backend: PHP
Database: MySQL

# Installation
Clone the repository:
git clone https://github.com/your-username/college-event-management-system.git
Set up the database:
Create a MySQL database and import the provided SQL file to set up the necessary tables.
Modify the database connection settings in the config.php file.
Deploy the application on a local or web server with PHP support (e.g., XAMPP, WAMP, or a live hosting server).

Access the system by navigating to the appropriate URL.

# Usage

Admin Side:

Admins can log in and manage event registrations.
View, edit, and delete registrations as necessary.

User Side:

Users can browse available events and fill out an online form to register.
Information such as name, contact, and event details will be stored in the database.
